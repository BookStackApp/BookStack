## NEW: VENV SAFETY CHECK

The tool now includes runtime venv detection:

### Behavior
1. Checks if running in virtual environment
2. If NOT in venv and terminal is interactive (TTY):
   - Prints warning with setup instructions
   - Prompts user to continue or abort
   - Skips check in CI/CD (GITHUB_ACTIONS env var)
   - Skips check in non-interactive mode

### Implementation Details
- check_venv_and_prompt() function added
- Called from main() only if sys.stdin.isatty() is True
- Disabled for CI/CD environments (GITHUB_ACTIONS check)
- Non-blocking (user can continue if desired)

### Example Output
```
⚠️  WARNING: Not running in a virtual environment!
   It's recommended to use a venv to avoid conflicts:
   $ python3 -m venv venv
   $ source venv/bin/activate
   $ pip install -e .
   $ bookstack-migrate --help

Continue anyway? (y/n):
```

## DATA SOURCE SELECTION LOGIC

### Class: DataSourceSelector
Intelligently selects between database and API:

1. **Both Available + prefer_api=False** → Uses DATABASE (faster)
2. **Both Available + prefer_api=True** → Uses API
3. **Only DATABASE Available** → Uses DATABASE
4. **Only API Available** → Uses API
5. **Neither Available** → Fails with clear error

### Usage
```python
selector = DataSourceSelector(
    db_available=True,
    api_available=True,
    prefer_api=False  # or True to override
)
source = selector.get_best_source()  # Returns: 'database', 'api', or 'none'
```

### Logging
All selections are logged:
```
DataSourceSelector: DB=true, API=true, prefer_api=false
Using database (preferred method)
```
