## 📌 Project Overview

📖 **BookStack** is a documentation platform with a clean, intuitive design that requires only basic word-processing skills to use effectively. It provides:

✅ A simple, out-of-the-box experience.  
✅ Advanced features that do not interfere with core simplicity.  
✅ A relaxed and continuously evolving development philosophy.  

📌 **Note:** BookStack is **not** designed to be an extensible platform for unrelated use cases.

📜 Learn more about the project's philosophy in our [FAQ](https://www.bookstackapp.com/about/project-faq/).

## 🛠️ Development & Contributions

👨‍💻 Developers can check the [Development Guide](dev/docs/development.md) for source code contributions.  
🔧 To customize or extend an instance, refer to [Hacking BookStack](https://www.bookstackapp.com/docs/admin/hacking-bookstack/).  
📌 Follow our [Release Process](dev/docs/release-process.md) for versioning details.  

### 💡 Want to Contribute?

✅ [Submit Issues](https://github.com/BookStackApp/BookStack/issues/new/choose) for feature requests & bug reports.  
✅ **Before making pull requests:** Open an issue first to discuss changes.  
✅ Work on the `development` branch. Do **not** submit PRs to `release`.  
✅ Modify CSS/JS in `resources/`, **not** in `public/`.  

📜 **Code of Conduct:** [Read Here](https://github.com/BookStackApp/BookStack/blob/development/.github/CODE_OF_CONDUCT.md)

## 🌎 Translations
